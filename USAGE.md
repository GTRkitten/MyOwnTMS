# MyOwnTMS - Инструкция по использованию

## Быстрый старт

### Запуск приложения

1. **Из исходного кода:**
   ```bash
   python run.py
   ```

2. **Из EXE файла:**
   - Просто запустите файл `dist/MyOwnTMS.exe` двойным кликом

### Создание тест-кейса

1. Нажмите кнопку "Создать тест-кейс"
2. Заполните обязательные поля:
   - **Название** - краткое описание теста
   - **Предусловия** - условия перед выполнением
   - **Шаги** - последовательность действий (каждый шаг на новой строке)
   - **Ожидаемый результат** - что должно произойти
   - **Постусловия** - состояние после теста (опционально)
   - **Окружение** - браузер, версия, платформа (опционально)
3. Выберите приоритет (Low/Medium/High/Critical)
4. Прикрепите скриншоты (если нужно)
5. Нажмите "Сохранить"

### Создание баг-репорта

1. Нажмите кнопку "Создать баг-репорт"
2. Заполните обязательные поля:
   - **Название** - краткое описание ошибки
   - **Описание** - детальная информация
   - **Шаги воспроизведения** - как воспроизвести ошибку
   - **Ожидаемый результат** - что должно было произойти
   - **Фактический результат** - что произошло на самом деле
   - **Окружение** - браузер, версия, платформа (опционально)
3. Выберите приоритет и серьезность
4. Прикрепите скриншоты (рекомендуется)
5. Нажмите "Сохранить"

### Просмотр и редактирование

1. Дважды кликните на артефакт в списке для просмотра
2. Для редактирования нажмите кнопку "Редактировать"
3. Для удаления нажмите кнопку "Удалить"

### Экспорт документов

1. Выберите один или несколько артефактов (Ctrl+клик или Shift+клик)
2. Нажмите кнопку "Экспорт"
3. Выберите формат:
   - **PDF** - готовый документ для печати
   - **DOCX** - Microsoft Word формат
   - **MD** - Markdown для GitHub/документации
4. Выберите папку для сохранения
5. Каждый артефакт будет сохранен отдельным файлом

### Поиск и фильтрация

- Используйте строку поиска для поиска по ID и названию
- Фильтруйте по статусу, приоритету и серьезности

## Автоматические ID

- **Тест-кейсы**: TC-ДДММГГ-ННН (например, TC-250226-001)
- **Баг-репорты**: BUG-ДДММГГ-ННН (например, BUG-250226-001)

ID генерируются автоматически с инкрементом номера.

## Хранение данных

Все данные хранятся в локальной базе данных SQLite:
- При запуске из Python: `data/tms.db`
- При запуске из EXE: создается рядом с EXE файлом

Резервное копирование: просто копируйте файл базы данных `.db`

## Горячие клавиши

- **Ctrl+N** - Создать тест-кейс
- **Ctrl+B** - Создать баг-репорт
- **Ctrl+E** - Редактировать выбранный
- **Delete** - Удалить выбранный
- **Ctrl+S** - Сохранить (в диалоге редактирования)
- **Esc** - Закрыть диалог

## Советы

1. **Прикрепляйте скриншоты** - они помогают разработчикам понять проблему
2. **Детальное описание** - чем больше деталей, тем быстрее будет исправлен баг
3. **Структурируйте шаги** - каждый шаг на новой строке
4. **Связывайте артефакты** - создавайте связи между тестами и багами
5. **Регулярный экспорт** - экспортируйте документы для отправки разработчикам

## Структура проекта

```
MyOwnTMS/
├── dist/                 # EXE файл
│   └── MyOwnTMS.exe     # Исполняемый файл
├── data/                # База данных
│   └── tms.db          # SQLite база данных
├── exports/             # Экспортированные документы (создается автоматически)
├── src/                 # Исходный код
│   ├── config.py        # Конфигурация
│   ├── database/        # Модели и сессии БД
│   ├── services/        # Бизнес-логика
│   └── gui/            # Интерфейс
├── requirements.txt     # Зависимости Python
└── run.py             # Запуск приложения
```

## Поддержка

При возникновении проблем:
1. Проверьте версию Python (3.14+)
2. Установите все зависимости: `pip install -r requirements.txt`
3. Очистите кеш PyInstaller: удалите папки `build/` и `dist/`
